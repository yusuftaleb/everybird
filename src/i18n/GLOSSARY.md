Read this before you translate a string or add a language. English (`messages/en.ts`) is the source of truth; every other `messages/<lang>.ts` has exactly its keys.

## Register

- **Spanish (es):** neutral, reading naturally in Spain and Latin America. "Tú", never "vosotros" or "usted". No regional words: "dispositivo" (not "ordenador" or "computadora"), "archivo", "descargar", "compartir".
- **Portuguese (pt):** Brazilian Portuguese with "você". Visitors in Portugal get this UI with pt_PT bird names.
- **Dutch (nl):** standard Netherlands Dutch that reads naturally in Flanders. Informal "je/jij", never "u".
- **Polish (pl):** informal "ty" ("Twoja lista", "Dodaj"), never "Pan/Pani". Never a second-person past tense: it shows the reader's gender ("pobrałeś/pobrałaś"). Use the imperative, the present, the impersonal "-no/-to" form for what happened ("Zapisano", "Usunięto", "Nie udało się …") or a participle ("kopia pobrana tam wcześniej"). Polish has three plural forms, so every Polish plural carries `one` (1), `few` (2–4, 22–24: "{n} gatunki") and `many` (0, 5+, teens: "{n} gatunków"), with `other` for fractions; where a name fills a slot, prefer the label form ("Usunięto: {name}", "Od: {month}"), which needs no agreement. Never decline a name or a variable ("Yusufa"), since the value can't follow; the link texts About checks against the nav ("Ustawienia") stay in the nominative. Typographic quotes are „…”. Numbers group with "." like es, pt and nl (count-box.ts sizes the count for "," and "." only). The whole file is an LLM draft awaiting a fluent speaker's review.
- **French (fr):** standard French that reads naturally in France, Belgium, Switzerland and Quebec, with informal "tu" ("Ta liste", "Ajoute"), never "vous", matching the informal register of es, pt and nl. Numbers group with "." (count-box.ts sizes the count for "," and "." only; French would use a narrow space). Bird names: France's (eBird `fr_FR`) for every French reader except Canada, which gets eBird's plain `fr` (North American French). The whole file is an LLM draft awaiting a fluent speaker's review.
- **German (de):** standard German (Germany) that reads naturally in Austria and Switzerland, with informal "du" ("Deine Liste", "Füge … hinzu"), never "Sie". Sentence case keeps every noun's capital (the family-label test allows it). Numbers group with ".". Bird names are eBird's one German set (`de_AT` and `de_CH` return it too). The whole file is an LLM draft awaiting a fluent speaker's review.
- **Italian (it):** standard Italian, with informal "tu" ("La tua lista", "Aggiungi"), never "Lei" or "voi", matching the informal register of es, fr and de. Numbers group with "." and use "," for decimals, as Italian does. Bird names: eBird's `it` set has only 737 names of its own, so where it repeats the English name the build takes the IOC World Bird List v15.2 name of the matched huashu record (`IOC_COLUMNS` in `build-names.ts`, credited on About); eBird has no Italian group or family names, so every family label is in `data/i18n/families.it.json` and group names stay English. The whole file is an LLM draft awaiting a fluent speaker's review.
- **Swedish (sv):** standard Swedish (Sweden) that reads naturally in Finland, with informal "du" ("Din lista", "Lägg till"), as Swedish apps always write. Numbers group with "." and use "," for decimals: Swedish groups with a space, but count-box.ts sizes the count for "," and "." only (as for pl and fr). Bird names: eBird's `sv` set, with the IOC World Bird List v15.2 names switched on for any it lacks (`IOC_COLUMNS`; none are needed in taxonomy 2026). eBird's names are lower case and the build capitalises the first letter. Typographic quotes are ”…”. The whole file is an LLM draft awaiting a fluent speaker's review.
- **Danish (da):** standard Danish with informal "du" ("Din liste", "Tilføj"), never "De". Numbers group with "." and use "," for decimals, as Danish does. Bird names: eBird's `da` set, with the IOC World Bird List v15.2 name of the matched huashu record where eBird only repeats the English one (`IOC_COLUMNS`, credited on About). eBird's Danish groups are Title Case and name Callaeidae and Meliphagidae alike, so `data/i18n/families.da.json` also overrides those. Search folds ø to "o" and æ to "ae" (`foldName`). The whole file is an LLM draft awaiting a fluent speaker's review.
- **Russian (ru):** informal "ты" ("Твой список", "Добавь"), as es, pl, fr and de; for the same reason as Polish, never a second-person past tense (it shows the reader's gender: "скачал/скачала"): the imperative, the present, impersonal forms ("Сохранено", "Удалено", "Не удалось …") or a label form that needs no agreement ("Удалено: {name}", "Начало: {month}"); never decline a variable. Plurals carry `one` (1, 21), `few` (2–4, 22–24) and `many` (0, 5–20, 25…), as Polish's. Quotes are «…». Numbers group with "." and use "," for decimals (count-box.ts sizes the count for "," and "." only; Russian groups with a space). Interface text draws in Noto Sans (Satoshi and Cabinet Grotesk have no Cyrillic), mono labels in Geist Mono's Cyrillic. Bird names: eBird's `ru` set, with the IOC World Bird List v15.2 name where eBird only repeats the English one (`IOC_COLUMNS`, credited on About). eBird's Russian groups are often order names ("…образные") or Title Case, so `data/i18n/families.ru.json` overrides those. Search keeps Cyrillic and reads ё as е (and й as и). The whole file is an LLM draft awaiting a fluent speaker's review.
- **Japanese (ja):** polite plain form, です/ます in sentences, short nouns on buttons and headings ("設定", "追加", "共有"); no keigo beyond です/ます. Punctuation 、。「」, full-width （） and ：; no spaces between Japanese words, nor between Japanese and Latin words or digits ("eBirdから", "197種"). One plural form (`one` and `other` alike). Numbers group with "," and use "." for decimals. Short months are "1月" … "12月", so dates read "2026年9月" and "11月6日" (`yearFirst` in `format.ts`). Interface text draws in Noto Sans JP. Bird names: eBird's `ja` set (katakana), with the IOC World Bird List v15.2 name where eBird only repeats the English one (`IOC_COLUMNS`, credited on About). eBird has no Japanese group names, so every family label is in `data/i18n/families.ja.json` (the 日本鳥類目録's 科 names where they exist) and group names stay English. Search reads hiragana as katakana and keeps Han; words are matched on spaces ("3月 から 5月"), except a year with 年, a month like "3月" and the one-word periods 今年, 去年, 今月 and 先月; since and until follow the date ("2024年 から"). The whole file is an LLM draft awaiting a fluent speaker's review.
- **Simplified Chinese (zh-Hans):** mainland usage, neutral, 你 (never 您), plain imperative labels ("添加", "分享", "下载"). Punctuation ，。“”（）; no spaces between Chinese words, nor between Chinese and Latin words or digits ("来自eBird", "197种"). One plural form. Numbers group with "," and use "." for decimals; dates read "2026年9月", "11月6日" (`yearFirst`). Interface text draws in Noto Sans SC. The code is `zh-Hans` everywhere (URL, cookie, `<html lang>`, analytics); a browser's zh, zh-CN, zh-SG or any other zh tag but Traditional's (see zh-Hant) chooses it (`langCode`). Bird names: eBird's `zh_SIM` set (all 11,201 of its own). eBird's Simplified groups name most families; `data/i18n/families.zh-Hans.json` labels the rest. Search keeps Han and matches a word anywhere in a name (no spaces to split at); words are matched on spaces ("从 3月 到 5月"), except a year with 年, a month like "3月" and the one-word periods 今年, 去年, 本月 and 上个月; since and before may follow the date ("2020年 以来"). No conversion between Simplified and Traditional. The top bar marks it 简 (`langBadge`). The whole file is an LLM draft awaiting a fluent speaker's review.
- **Traditional Chinese (zh-Hant):** Taiwan usage that reads in Hong Kong and Macau, neutral, 你 (never 您), plain imperative labels ("新增", "分享", "下載"), Taiwan vocabulary ("設定", "檔案", "連結", "資料") and Taiwan's family names where they differ from the mainland's. Punctuation ，。「」（）; no spaces between Chinese words, a space between Chinese and Latin words, digits or a `{variable}` ("從 eBird 匯入"). One plural form. Numbers and dates as Simplified (`yearFirst`). Interface text draws in Noto Sans TC. The code is `zh-Hant` everywhere; a browser's zh-TW, zh-HK, zh-MO or any zh-Hant… tag chooses it (`langCode`; its Accept-Language rule comes before Simplified's). Bird names: eBird's `zh` set (794 of its own), with the IOC World Bird List v15.2 zh-Hant name where eBird only repeats the English one (`IOC_COLUMNS`, credited on About); written directly, never converted from Simplified. Search as Simplified (今年, 去年, 本月, 上個月; "2020年 以來"). The top bar marks it 繁. The whole file is an LLM draft awaiting a fluent speaker's review.
- **Every language** follows DESIGN.md "Voice and copy": plain words, second person, short sentences, sentence case (mono labels are uppercased by CSS, never in the string), no em dashes, no exclamation marks (nor "¡"), no emoji, no hype. Never "seen" for the list (heard-only birds count too): "on your list".

## Templates

- `{name}` is a variable: keep every one the English string has, spelled the same. You may move it.
- `<link>…</link>` (any `<tag>`) wraps words that become an element. Keep every tag; translate the words inside.
- Plurals are `{ one, other }`: `one` is used exactly when the number is 1, `other` for everything else (0 included). Write `{n}` where the number goes. A language with more forms (Polish, Russian) adds `few` and `many`; Intl.PluralRules then picks the form for the dictionary's language (`plural` in `core.ts`), and a missing one falls back to `other`.
- Numbers and dates come from `ui.num` and `ui.date` through `src/i18n/format.ts`, never from `Intl` or `toLocaleString`.

## Stays English in every language

- The credit lines `FOOTER_LINE` ("everybird.yusuftaleb.com · stickers by huashu") and `SHARE_CREDIT` (attribution; only the date stamp after them is translated).
- CSV column headers and the CSV's English name column, download file names, the backup JSON, stored data (`titleFromOldName`'s output), analytics values.
- Scientific names, IUCN abbreviations (LC … DD; their full names are translated), province and county names.
- Names: Everybird, eBird, iNaturalist, GitHub, CSV, JSON. These may equal English; `ALLOW_SAME` in `tests/i18n.test.ts` lists every value allowed to.

Country names come from `Intl.DisplayNames` (the one `Intl` exception), bird and family names from eBird's localized taxonomy (the names files).

## How to add a language

1. `src/i18n/langs.ts`: add the code to `LANGS`, and its entries to `HTML_LANG` and `LANG_NAMES` (the name in its own language).
2. `src/i18n/messages/<lang>.ts`: `export const <lang>: Messages = { … }`, every key of `en.ts` translated with this glossary (add the new column above). `npx tsc --noEmit` names any missing key and every `Record<Lang, …>` that needs an entry (`OG_LOCALE`, the smart search's word tables in `src/lib/search/dates.ts` and `smart.ts`); `tests/i18n.test.ts` names extra, empty or untranslated ones. Add it to `MESSAGES` in `src/i18n/server.ts` (the test helper `tests/i18n-render.tsx` imports that map), and to the language maps the tests and e2e specs keep (`OTHERS` in `tests/i18n.test.ts`, `NAV` in `tests/topbar-fit.test.ts`, `LANGS` in `tests/count-box.test.ts`, `MESSAGES` in `e2e/flows.spec.ts` and `e2e/settings.spec.ts`), or their checks skip it.
3. The count label must be at most 8 characters (`COUNT_LABEL_CHARS`), and the group separator no wider than "," (only "," and "." are measured).
4. The nav labels must fit the top bar: `tests/topbar-fit.test.ts` models it from the fonts' measured advances. A letter outside Latin-1 needs `scripts/dev/measure-glyphs.ts` to measure it (`EXTRA_CODEPOINTS`), Geist Mono's next/font `subsets` to load it (`app/[lang]/layout.tsx`) and the link preview's fonts to cover it (`pickFaces` in `og-server.ts`), and `foldName` (`src/lib/species/resolve.ts`) must fold it if NFD can't (Polish "ł").
   A script Satoshi and Cabinet Grotesk lack (Cyrillic, kana, Han) is drawn in a Noto family: `NOTO` in `app/[lang]/layout.tsx` links it on that language's pages only and `--font-noto` in `tokens.css` puts it after the Latin fonts by `:lang()` (the share images read it); `searchKey` must keep the script (`name-search.ts`). The fit tests measure Cyrillic in Noto Sans (`CYRILLIC` in the glyph script) and take a kana or Han character as one em; the count label is counted in `labelCells` (a full-width character is two). A link preview needs a face for it in `og-server.ts`'s `SOURCES` (Russian's Noto Sans), or, for Japanese and Chinese, only `ogLang` (next/og borrows the font by the card's `lang`).
5. The `ui_language` analytics values: `src/lib/analytics.ts` and `workers/stats/src/event.ts` together; the stats Worker must be deployed before the new value counts.
6. Nothing in `routes.ts`: its cookie value and `Accept-Language` rules derive from `LANGS`, so `/about` reaches `/<lang>/about` by itself.
7. eBird's locales for its bird names in `NAME_LOCALES` (the names build), with their regional fallbacks, and `pickNameLocale`; group names in `GROUP_LOCALES` (`build-groups.ts`). Until those exist the language shows English bird and group names.
