# Date Stamp on Share Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every share image (story, post, square) says when it was made, "As of 14 Nov 2026", small and muted at the end of its footer line; link previews stay without it.

**Architecture:** One small pure module, `src/lib/share/stamp.ts`, formats the stamp from a `Date` and a strings object (English now; the i18n layer of items 1 and 7 passes its own strings later) and joins it to a footer line. `drawShareImage` builds its footer text as `withStamp(FOOTER_LINE, asOfDate(now))` and hands that whole text to the existing `placeCredit`, so the never-cut rule (20px down to 17px beside the wordmark, else its own line) covers the stamp too. `FOOTER_LINE` itself is unchanged, so the link preview (`app/s/[token]/opengraph-image.tsx`) stays as it is. About's "How it works" mock share image mirrors the product with a fixed demo date.

**Tech Stack:** TypeScript, canvas 2D (`src/lib/share/image.ts`), Vitest, Playwright.

**Spec:** `docs/superpowers/plans/2026-11-15-next-features.md`, item "4. Date stamp on share images" (approved by Yusuf). Read `AGENTS.md` and `DESIGN.md` "Share image" first.

## Global Constraints

- Every share image (story, post, square) carries the date it was made: "As of 14 Nov 2026".
- Small and muted, in the footer next to the Everybird address. Always on, no switch.
- Localized with the UI language (Spanish "Al 14 nov 2026", Portuguese equivalent): no i18n layer exists yet, so English only now, through a swappable strings argument.
- Not on link previews (a link always shows the list as it was when shared).
- The sticker credit stays on every image: the footer line is never truncated and never loses "stickers by huashu" (`placeCredit`, `CREDIT_MIN` 17).
- `FOOTER_LINE` stays exactly `everybird.yusuftaleb.com · stickers by huashu` (the link preview and `e2e/about.spec.ts` pin it).
- Ports 3000/3001 are Yusuf's: e2e uses 3100/3200/4100 only. No push, deploy or posting.

**Decisions (builder's calls, made here):**
- Placement: the stamp ends the existing footer line after a " · " separator, same font (Geist Mono 400), same Muted colour, same size: `everybird.yusuftaleb.com · stickers by huashu · As of 14 Nov 2026`. One line, so the footer's height and the layout (`cardLayout`, the story's safe zones) don't change.
- Date: the device's local calendar date (`getFullYear/getMonth/getDate`) at the moment the image is drawn; day without a leading zero ("4 Nov 2026"); English months from `format.ts`'s table (`Sep`, as "Latest lifer · Sep 2026"). Not `Intl`: `en-GB` gives "Sept" in current ICU and engines differ.
- About demo: shows the stamp with a fixed date, `new Date(2026, 10, 6)` → "As of 6 Nov 2026", matching its fixed "Imported 6 Nov" (a live date would differ between the server-rendered poster and the client, and change daily).

## Review Focus

1. A device near midnight or far from UTC: the stamp is the local day, not the UTC day (Task 2's e2e runs in `Pacific/Auckland` with a UTC instant that is already the next day there).
2. A longer stamp (a future locale) with a wide wordmark: the whole line moves to its own line or shrinks, the credit and the stamp never cut (Task 1's `placeCredit` tests).
3. The link preview picking up the stamp by sharing `FOOTER_LINE` (Task 1's source check on `opengraph-image.tsx`).
4. A broken clock (`Invalid Date`): no "NaN" on the image, the footer line without a stamp (Task 1).
5. About's mock image: a longer footer line clipped by the image's `overflow: hidden` (Task 3's bounding-box check).

**Interfaces:**
- Produces (`src/lib/variants.ts`, client-safe, no React import except the hook):
  - `export function variantsEnabled(host?: string): boolean` — false when the host is `everybird.yusuftaleb.com` (the production domain, `SHARE_ORIGIN`'s host) or `process.env.NEXT_PUBLIC_VERCEL_ENV === 'production'`; true otherwise (local dev, e2e, Vercel previews).
  - `export function parseVariants(search: string): Record<string, string>` — `?v=b` → `{ '*': 'b' }`; `?v=stamp:b,pill:c` → `{ stamp: 'b', pill: 'c' }`; mixed allowed (`?v=b,pill:c`); letters a–z only, anything else ignored.
  - `export function readVariant<T extends string>(feature: string, options: readonly [T, ...T[]], search?: string): T` — the feature's own key wins over `*`; a value not in `options` falls back to `options[0]`; disabled → `options[0]`. When `search` is omitted it reads `location.search`, and a `v` param present there is remembered in `sessionStorage` `everybird:v` (every access in try/catch) so the choice survives in-app navigation for the tab; `?v=` (empty) clears it.
  - `export function useVariant<T extends string>(feature: string, options: readonly [T, ...T[]]): T` — returns `options[0]` during SSR and the first client render (no hydration mismatch), then the read value after mount.
- Produces (`stamp.ts`): `export type StampAt = 'end' | 'address'`; `export function stampedFooter(site: string, credit: string, stamp: string, at: StampAt = 'end'): string` → `end`: `site · credit · stamp`; `address`: `site · stamp · credit`; empty stamp → `site · credit` (equals `FOOTER_LINE` for the real values).
- Produces (`image.ts`): `ShareImageOpts.stampAt?: StampAt` (default `'end'`); `drawShareImage` builds the line with `stampedFooter(SITE_LABEL, 'stickers by huashu', asOfDate(now), stampAt)`. `FOOTER_LINE` unchanged.
- Variant key: `stamp`, options `['a', 'b']` → a = `'end'` (default, today's), b = `'address'`.
