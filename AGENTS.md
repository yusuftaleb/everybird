# Everybird: agent instructions

Everybird turns any birder's life list into a sticker collage. Import an eBird export or an iNaturalist username, or tick birds by hand; filter, edit and share. The list stays in the browser. It uses Yusuf's personal-site design system, and its collage page mirrors his /lifelist. Pages: Collage `/`, Settings `/settings`, About `/about`, shared view `/s/[token]`. Read these before any work:

- **Design system:** `DESIGN.md` (tokens, type, components, motion, voice, accessibility; sidecar `.impeccable/design.json`, product context in `PRODUCT.md`). Match it, and match `/lifelist`, for any UI work.
- **Spec (approved by Yusuf, 2026-11-05):** `docs/superpowers/specs/2026-11-05-everybird-design.md`, with "Changes after approval" at its end.
- **Plan (25 tasks):** `docs/superpowers/plans/2026-11-05-everybird.md`
- **Validation:** `docs/validation.md` (launch checklist; aggregates only, no personal data).

## Rules

- **Never commit personal data.** `private/` holds Yusuf's real eBird exports and his `lifelist.json`, and it's git-ignored. Test fixtures must be synthetic. Never commit coordinates, checklist comments or anything copied from those files.
- **Credit the stickers.** On the site, the footer's "All credits" link (→ /about#credits) and the full credit on About; on share images and link previews, the footer line "everybird.yusuftaleb.com · stickers by huashu" (`FOOTER_LINE` in `image.ts`); in the share text (`navigator.share`), the full credit with the licence and link, "Stickers: huashu-bird-sticker (CC BY 4.0) github.com/alchaincyf/huashu-bird-sticker" (`SHARE_CREDIT`). The license link is https://github.com/alchaincyf/huashu-bird-sticker.
- **Never commit the font files** for Satoshi and Cabinet Grotesk. Load them from Fontshare's CSS.
- **Read-only references** in Yusuf's website repo (`/Users/yusuf/orca/projects/personal_website/framer-site/`): `code-components/LifeList.tsx`, `code-components/PlacesMap.tsx`, `scripts/lifelist/*.py` and `HANDOFF.md` ("Life list v4" to "v7.7"). Don't edit that repo.
- **Ask Yusuf first, every time,** before anything outward-facing: creating GitHub repos, pushing, enabling GitHub Pages, creating or deploying the Vercel project, or posting anything. That's plan Task 25.
- **Keep this file current** as commands and structure change.

The script never uploads, pushes or calls GitHub.

## Structure

- `app/`: Next.js app router (layout, pages). Imports styles via `@/styles/...`.
- Routes (Collage, Settings, About): `app/(app)/layout.tsx` wraps `/` (`Home`), `/settings` (`SettingsPage`) and `/about` (static, `app/(app)/about/page.tsx` + `about.css`: what Everybird is, how it works, True size, the privacy note, and every credit under `#credits`, opening with "Made by Yusuf Taleb") in `EverybirdProvider` (`src/components/app/EverybirdProvider.tsx`: the store from `useEverybird`, regions and `use-import-jobs.ts`, the imports in flight; `mineSoon` says whether this device holds a list as soon as storage is read, before the species file), with `TopBar` above and `SiteFooter` below, so an import started on /settings keeps running while the birder moves between them. On `/` with no stored list, `useEverybird({ deferIfEmpty })` fetches the species file at an idle moment. Old addresses redirect (page-level `redirect()`): `app/make` → /settings, `app/my` → /, `app/credits` → /about#credits. `/s/[token]` sits outside the group (its own `TopBar`, no store) and never loads or touches the saved list: h1 "<name>'s life list" (or "A birder's life list"), the line "Everybird turns a birder's life list into a sticker collage.", "Make yours" (→ /settings) beside the title and again after the legend; a broken link says "This link didn't open" and shows the sample.
- `Home`: the birder's `CollagePage` when the device holds a list, else `Landing`. `Landing`: a one-row hero (h1 "Every bird you've ever seen.", one lede, "Make yours" → /settings) over `SampleDemo` (the pre-packed sample of a made-up demo birder, stats line "Sample: a demo birder's life list · …", `src/lib/list/sample-pack.ts`: its own mini species index and regions, seed layouts shown until the layout worker's first answer; the same `FilterBar` as every collage (no strip, no sideways scroll); the landing's page gap is 16px from 720px so the birds keep a little under half of a 1280×800 first screen: the sample's order chips wrap onto four rows). On the first visit `Landing` also shows `Welcome.tsx` (portalled to the body): the line "Every bird you've ever seen, as a sticker collage.", "Make mine" (→ /settings#sources, the ways in) and "Explore the sample"; ✕, Esc and a press outside are Explore; a card from 601px, the phones' bottom sheet at 600px and under, a light scrim (.12) so the sample stays in view; focus starts on Make mine, Tab stays inside, and on close returns to the sample's view tabs.
